# Інструкція власника CyberOS

Статичний сайт інструкції для власника кіберклубу на CyberOS: сім розділів
від реєстрації до першого клієнта за комп'ютером. Кожна сторінка — знімки
панелі з підсвіченими полями, покрокові пояснення, плашки-попередження,
чекліст і відео проходу. Приватні дані на знімках розмиті.

| Розділ | Файл |
|---|---|
| 1. Заведення клубу | `instruction-01-club-setup.html` |
| 2. Зони і пристрої | `instruction-02-zones-devices.html` |
| 3. Тарифи | `instruction-03-tariffs.html` |
| 4. Ігри та застосунки | `instruction-04-games.html` |
| 5. Shell у панелі | `instruction-05-shell.html` |
| 6. Встановлення на ПК | `instruction-06-install.html` |
| 7. Клієнти | `instruction-07-clients.html` |

`index.html` — обкладинка зі списком розділів. Усе інше — `assets/`
(стилі й скрипт), `shots/` (знімки) і `videos/` (відео проходу).
Жодного бекенду: це звичайні файли, які відкриваються і з диска.

## Де це живе

**https://cherniak27031997.github.io/cyberos-guide/**

GitHub Pages віддають сайт із ветки `main`, тека `/` (root). Тобто
достатньо запушити в `main` — за хвилину зміни вже на сайті, жодних
Actions не потрібно. Файл `.nojekyll` вимикає Jekyll, щоб він нічого не
переписував.

Спроба вмикати Pages через Actions (`configure-pages` з
`enablement: true`) у новому репозиторії падає: типово `GITHUB_TOKEN`
має лише права на читання, тому workflow не може ввімкнути Pages сам.
Тому джерело виставлене вручну в Settings → Pages, а workflow прибраний.

Репозиторій публічний — на безкоштовному плані Pages інакше не працюють.

## Звідки беруться сторінки

Сайт не редагується руками. Джерела — у репозиторії тестів
`cyberos-ui-tests`, тека `guide/`:

- `record_*.py` — знімають матеріали з демо-клубу (Playwright) і пишуть
  відео проходу;
- `build_*.py` — рендерять HTML-розділи зі знятих матеріалів;
- `build_site.py` — збирає цю теку: загортає розділи в повний документ,
  генерує `index.html` і копіює лише ті знімки й відео, на які є посилання;
- `build_onepage.py` — та сама інструкція однією сторінкою (усе всередині
  файлу), щоб відкривати з телефона без сервера.

Після змін у панелі достатньо перезапустити відповідний `record_*.py` +
`build_*.py`, потім `build_site.py`.

Розділ 6 — єдиний, знятий не браузером: кадри інсталятора зроблені на живій
Windows-машині через `tools/wini.sh`.
